## 先说结论

`jingma-ppt-skill` 是一个用来生成**单文件 HTML PPT** 的 Skill：打开浏览器就能讲，不需要装翻页工具，也不需要导出 PDF。

它解决的不是“做一张好看的封面”，而是把**写内容、排版、演示、讲稿、计时**放进一个文件里。适合线下分享、行业交流、产品发布和内部培训。

> 原作 `guizang-ppt-skill` 来自歸藏，鲸码在这个基础上做了改造与维护。

在线预览：[https://whale-code.com/skill-intro/ppt/index.html](https://whale-code.com/skill-intro/ppt/index.html)

## 三种视觉风格

### 风格 A · 电子杂志 × 电子墨水（默认）

- WebGL 流体 / 等高线 / 色散背景
- 衬线标题（Noto Serif SC + Playfair Display）+ 无衬线正文 + 等宽元数据
- 适合：人文分享、行业观察、商业发布、需要“杂志感”的演讲
- 美学锚点：像 *Monocle* 杂志贴上了代码

### 风格 B · 瑞士国际主义（Swiss Style）

- WebGL 极细网格 + 点阵背景
- 全程无衬线（Inter + Helvetica + Noto Sans SC）+ 极致字号对比
- 高反差功能色：克莱因蓝 IKB / 柠檬黄 / 柠檬绿 / 安全橙
- 适合：科技产品、数据汇报、设计/工程分享、年度总结
- 美学锚点：Massimo Vignelli + Helvetica Forever

### 风格 C · 卡通涂鸦（Cartoon Doodle）

- Canvas 纸张纹理 + 蜡笔颗粒 + 漂浮手绘贴纸背景
- 圆润手写字体（ZCOOL KuaiLe + Patrick Hand + Comic Neue）+ 高饱和糖果色
- 圆角 + 软投影 + 胶带 / 便利贴 / 票券 / 邮票 / 涂鸦线条
- 适合：儿童 / 教育 / 趣味科普 / 品牌周边 / Demo Day 轻松场

## 三种风格共享的能力

- 横向翻页：键盘 ← →、滚轮、触屏、ESC 总览
- 右下角 `P` 演讲者模式：当前/下一页 16:9 预览、讲稿备注、分组计时
- 内嵌宫格选页、标题/目的/讲稿备注
- 排练记录、可选自动翻页
- 激光笔 / 圈选
- 观众屏黑白屏 / 冻结、同步状态与断线恢复
- 演前检查清单
- Lucide 图标、Motion One 入场动效（本地 + CDN 双保险）

## 什么时候适合用

**适合：**

- 线下分享 / 行业内部讲话 / 私享会
- AI 新产品发布 / demo day
- 带有强烈个人风格的演讲
- 需要“一次做完，不用翻页工具”的网页版 slides

**不适合：**

- 大段表格数据、图表叠加（用常规 PPT 更稳）
- 培训课件（信息密度不够）
- 需要多人协作编辑（这是静态 HTML）

## 这套 Skill 的工作方式

1. 先确定演讲目标、听众和时长
2. 选风格（A/B/C）和主色
3. 按“封面 → 问题 → 论点 → 证据 → 方案 → 收尾”搭结构
4. 每页只放一个核心观点，标题写结论，正文放证据
5. 讲稿备注单独写，不要塞进页面
6. 用 `P` 模式排练，检查时间、翻页和观众屏同步
7. 演前检查：字体、图片、动效、离线可用性

## 几个使用建议

- **一页一个观点**：网页 PPT 的横向空间大，但信息密度低，别把 Word 搬上去。
- **标题写结论**：观众扫一眼标题就知道你要说什么，正文只做支撑。
- **讲稿和页面分离**：讲稿放备注，页面留白，演示时才不会变成念稿。
- **提前离线测试**：字体、CDN、WebGL 在不同机器上表现不同，现场网络不可控。
- **别用它做数据大表**：复杂表格和图表还是常规 PPT 或 Excel 更合适。

## 和传统 PPT 的区别

| 维度 | 传统 PPT | 网页 PPT |
|---|---|---|
| 打开方式 | PowerPoint / Keynote | 浏览器 |
| 翻页 | 软件控制 | 键盘/滚轮/触屏 |
| 动效 | 内置动画 | CSS/JS/WebGL |
| 演讲者视图 | 支持 | 内置 `P` 模式 |
| 分享 | 文件/PDF | 一个 URL 或单文件 |
| 协作 | 多人编辑 | 静态文件，不适合多人协作 |
| 适合 | 正式汇报、打印 | 分享、发布、个人风格演讲 |

## FAQ

**Q：需要联网吗？**  
A：动效和字体做了本地 + CDN 双保险，但首次加载和字体仍可能依赖网络。正式演讲前在目标机器上离线测试一遍。

**Q：能导出 PDF 吗？**  
A：浏览器打印可以导出，但横向翻页和动效会丢失。需要打印版时建议单独做一份。

**Q：可以商用到客户项目吗？**  
A：可以用于自己的分享和项目演示。二次分发或改造时请保留原作者与鲸码的署名说明。

**Q：支持手机吗？**  
A：支持触屏翻页和基本浏览，但演讲者模式、观众屏同步更适合桌面端。
